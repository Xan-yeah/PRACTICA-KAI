Проект выполнен студентами КНИТУ‑КАИ (Казанский национальный исследовательский технический университет им. А.Н. Туполева‑КАИ).
Сайт вуза: https://kai.ru/

1. Назначение
   Программный комплекс предназначен для работы киосковых терминалов автопарковки: выдача пропусков, оплата, проверка выезда.

2. Системные требования (минимальные)
   - ОС: Windows 10 / 11 (x64), права администратора;
   - .NET Framework 4.8.1;
   - RAM: 2 GB;
   - Диск: 200 MB свободного места;
   - Разрешение экрана: минимум 1024×600;
   - USB‑порты для флеш‑карт;
   - Опционально: доступ в интернет для NTP.

3. Подготовка
   - Установите .NET Framework 4.8.1;
   - Запустите инсталлятор от имени администратора;
   - При необходимости временно отключите антивирус.

4. Конфигурация по умолчанию
   - Папка установки: C:\Program Files\AvtoParkingKAI\
   - Логи: C:\ProgramData\AvtoParkingKAI\Logs\
   - Пароль обладателя по умолчанию: qwerty (хранится в виде SHA‑256 хэша). Рекомендуется сменить.

код продукта:1234567890

5. Риски и рекомендации
   - Установка без прав администратора может привести к проблемам с сервисами и хуками.
   - Настройте киоск‑режим и ограничьте системный доступ.
